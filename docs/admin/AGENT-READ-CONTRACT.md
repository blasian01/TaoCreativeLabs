## Read endpoint
`GET https://www.taocreativelabs.com/api/marketing/evidence` with machine Bearer JWT. No browser cookie accepted. GET only; other methods405. Private/no-store; no CORS wildcard. Separate projection deliberately excludes business data and owner/admin configuration. Query filters `app`, `platform`, `from`, `through` (inclusive ET publication dates), `status`, `format`. Bounds `limit`1–50(default25), `offset`0–100000; observations for this publication page limited100 with separate `observationOffset`. Follow `nextOffset` and `nextObservationOffset`; do not call partial pages complete. Full source observation history cap/truncation explicitly disclosed. Account measurements returned only when no date filter, because account totals cannot silently inherit publication-date windows. Portfolio only: up to25matching experiments included as preview, not exhaustive task tracker. Creative responses always return an empty experiments array; they retain permitted publication/content/engagement fields.

DTO contains schemaVersion/role/retrievedAt/snapshotAt/lastSyncAt/coverage and pagination; accounts `{app,platform,url,owner,source,verifiedAt}`; publications `{app,platform,date,slot,status,permalink,caption,concept,conceptId,scriptId,hook,format,mediaRef,publishedAt,distribution,source,retrievedAt,task,effort}` (effortnullforcreative); observations `{app,platform,entityUrl,entityType,metric,value,unit,observedAt,retrievedAt,periodStart,periodEnd,source,denominator,attribution}`; experiments `{id,app,owner,hypothesis,status,metric,evidence,outcome}`.

Missing fields remain null/unknown. `publishedAt` is actual sourced timestamp, never localdate/last-sync; retrievedAt distinct from original observedAt. Draft/scheduled/published/blocked/failed/unknown distinct; legacydeferred preserved. Format video/text/image/carousel/unknown; organic/paid/unknown separately sourced. `mediaRef` is opaque `archive:...` scoped reference, not an exposed filesystem path or access token. Actual secured preview retrieval not provisioned; no local-file browser bridge. Concept/script/hook/asset links are optional source evidence; counts alone never certify distinct creative concepts versus crossposts. `task` has owner/status/dependency when supplied. Effort/cost only sourced measured values, no assumed labour hours or ROI. Dollar offer cards are not marketing ROI.

Attributed funnel observations require explicit verified source/definition/cohort/window/denominator; absent proof never upgrades views/clicks/ads to acquisition/ROI. Unknown denominator and zero denominator remain distinct; no computed rate from0denominator. No universal winner ranking. Comparable account/platform/post age and organic/paid baseline required. Collect24h/72h/7day observations only when sourced; do not fabricate retrospective points. Primary visits→signup/install→first useful action→paid linkage needs verified cohort attribution. Source data currently lacks most downstream metrics.
