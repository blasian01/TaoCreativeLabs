# Founder YouTube scripts

Owner route `/admin/youtube`, owner API `/api/admin/youtube`, same GitHub subject/session as existing admin. No marketing machine token or ingestion key authorizes this route. GET/POST deny before store access; POST additionally requires matching Origin, bounded JSON and strict schema. No publishing/upload action is provided. Business-process checkbox tags cross-app topics without creating another SaaS.

Initial ingestion is **manual owner import**, not daily automated sync. Story writes drafts in Shared/Growth/YouTube; an authorized adapter prepares one JSON per script outside the repository. Owner selects Import JSON in the workspace (uses their current session), then reads/edits/saves. Do not distribute owner cookies, broad writer keys or read-client credentials to Story. Source files/versions remain untouched; future automated submission needs separate narrowly scoped binding and verification, not reuse of read:marketing.

JSON fields: `id` stable lowercase app/date/topic identifier (3–100 chars), `app` reelchef/aura/agentic-media/glyph/notare, `date` realYYYY-MM-DD ET day, `title`1–300, `body`1–120000 full spoken script, `notes`≤20000 for title options/hooks/sections/shotlist/checklist/CTA/description/thumbnail/sources/unknowns, `status`, `businessProcess`boolean, `recordingRef`empty or recording:opaqueID, `publishedUrl`empty or actualYouTube permalink for published tracking. Defaults are documented by model.ts. No raw private filesystem links or credential values in draft artifacts. Statuses: draft,needs-facts,ready-to-record,recorded,editing,ready-for-review,ready-to-upload,published. Published needs a YouTube link; entering it tracks an existing publication, never uploads.

POST envelope `{mode:"import",baseVersion:0,script:{...}}` creates only. An exact repeat compares immutable version1 digest and returns current founder version with replayed:true/no write. Different content at same importID conflicts409; agent revisions never replace founder text. Owner save uses `{mode:"save",baseVersion:N,script:{...}}`; a single PostgreSQL CTE compare-and-swap updates only matching current version and atomically inserts immutable history. Stale/concurrent save409 keeps unsaved editor text. Caller-supplied version/timestamps/sourceDigest are rejected by strict draft schema. GET id+optional version reads current/history; list supports app/date/status/search/offset and returns200 summaries+truncated flag. UI applies server filters and loads further pages; long body/notes omitted from list. History displays latest200 version summaries, explicit version API can address earlier versions.

Uses existing `tao_admin_items` with isolated kinds `youtube_scripts` and `youtube_versions`; no DDL/new resource/migration. Existing marketing DTO maps known kinds and never includes scripts. Scripts are not public static payloads. Owner reads private/no-store, noindex inherited admin boundary. Text is React-escaped, not rendered as executable markdown/HTML.

Recording reference is an opaque coordination ID; no actual media storage, preview retrieval, folder watcher or recording is inferred. Word/time label is an approximate editable-text estimate at140wpm, not measured recording duration. Import does not certify factual claims or editorial readiness; retain needs-facts and original claim unknowns until founder/app-owner review.
